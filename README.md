# 🚀 Mesto - Интерактивная галерея

![Mesto Preview](https://Shklyaev0101.github.io/mesto-project-ff)

## 📌 Описание проекта

**Mesto** — это интерактивная веб-галерея, где пользователи могут загружать фотографии, лайкать их и изменять свой профиль.  
Проект разработан с использованием **HTML, CSS и JavaScript**. Реализована работа с **API** для сохранения данных на сервере.

## 🔥 Функциональность

✅ Добавление, удаление и лайк фотографий  
✅ Редактирование профиля и обновление аватара  
✅ Валидация форм перед отправкой  
✅ Адаптивная верстка

## 🛠️ Используемые технологии

- **HTML5** / **CSS3** (Flexbox, Grid, БЭМ)
- **JavaScript (ES6)**
- **API (Fetch, REST)**
- **Webpack** (сборка проекта)
- **Git и GitHub Pages** (деплой)

## 🛠️ Запуск проекта локально

1. **Склонируйте репозиторий:**
   ```bash
   git clone https://github.com/Shklyaev0101/mesto-project-ff.git
   cd mesto-project-ff
   ```
2. **Установите зависимости:**

   ```bash

   npm install
   ```

3. **Запустите проект:**

   ```bash

   npm run dev
   ```
